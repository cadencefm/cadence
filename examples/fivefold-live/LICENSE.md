# Fivefold Live material

The project, performance key scripts, and recorded take in this folder were created originally for Cadence using pure synthesis (`project.json`, `setup.keys.jsonl`, `perform.keys.jsonl`, `takes/set.take.jsonl`). They contain no third-party recordings, lyric text, or proprietary sample-library assets.
