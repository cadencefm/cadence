# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `main` branch.

| Version | Supported |
| --- | --- |
| `0.1.x` (`main`) | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub Issue for security vulnerabilities (for example: untrusted project/preset/sample/ReBirth `.rbs` file parsing memory safety or unbounded allocation issues, `--ctl` Unix socket permission issues, or path traversal on Save/Bundle/Import).

Instead, report vulnerabilities privately through [GitHub Security Advisories](https://github.com/cadencefm/cadence/security/advisories/new). Include reproduction steps and, if possible, a minimal test fixture. You can expect an acknowledgment within 7 days.
